# 💼 Job Tracker

A Python application for tracking job opportunities and applications, developed as part of a practical Python software development upskilling journey.

## 📝 Project Description

Job Tracker is a job application tracking system designed to help candidates manage job opportunities and keep track of their applications throughout the recruitment process.

The project is being developed incrementally to practise professional Python software development concepts, including object-oriented programming, clean code, type hints, testing, error handling, and software design.

**Current status:** Under development

## 🚀 Key Features

* Create and manage candidate information
* Store job opportunity details
* Create job applications for specific candidates and jobs
* Track application status through defined workflow stages
* Validate email addresses
* Record when an application was created
* Prevent invalid application status transitions

## 🛠️ Technology

* Python
* PyTest
* Git & GitHub

## 🧪 Running the Tests

From the project root, run:

```bash
pytest
```

The test suite covers the current application, candidate, and email functionality.
